# Week 6 Task: Evaluation and Recommendations for Healthcare Data Strategies (Capstone)

Simulated evaluation of the healthcare data strategy built in Weeks 1-4: maturity scorecard, gap analysis, prioritised recommendations and an 18-month roadmap. All data are **synthetic**.

## Files
| File | Purpose |
|---|---|
| `Evaluation_Report.docx` | Main deliverable: evaluation report |
| `evaluation.py` | Builds scorecard, charts and results |
| `data/maturity_assessment.csv` | Maturity scores (current vs target) with evidence |
| `data/recommendations.csv` | Impact, effort and timing per recommendation |
| `data/` (JSON and CSV from earlier weeks) | Evidence used in the evaluation |
| `charts/` | Four PNG charts |
| `results.json` | Computed values |

## Run
```
pip install pandas numpy matplotlib
python evaluation.py
```
